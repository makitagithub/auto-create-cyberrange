# Triage labels

| スキル上の役割 | GitHubラベル | 意味 |
| --- | --- | --- |
| needs-triage | needs-triage | 課題の評価が必要 |
| needs-info | needs-info | 追加情報待ち |
| ready-for-agent | ready-for-agent | 仕様が整い、エージェントが着手可能 |
| ready-for-human | ready-for-human | 人による実装・対応が必要 |
| wontfix | wontfix | 対応しない |

スキルが役割名を指定した場合は、対応するGitHubラベルを使用する。
